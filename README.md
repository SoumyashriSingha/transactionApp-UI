# transactionApp-UI

This is a reactive user-end functional UI similar to clone of an UPI app but with Dispute Raising feature against transactions. One can raise dispute like "Duplicate transfer", "failed transaction", "merchandise issue", and so on against that particular transaction history. User will be required to provide evidence in form of screenshot or photo which can be taken from gallery or the app can access the camera directly and you can take a picture of the receipt.

-----------------------
Tech stack:  
React.js  
React native  
Javascript  
CSS  

---------------------
⚙️ Installation & Setup  
1️⃣ Clone Repository  
git clone https://github.com/SoumyashriSingha/transactionApp-UI.git  
2️⃣ Navigate to Project  
cd transactionApp-UI  
3️⃣ Install Dependencies  
npm install   
4️⃣ Start Development Server  
npm run web  

The application will run on server -> http://localhost:8081/
